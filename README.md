# Techfest Signal / 30

Signal / 30 is an independent landing-page concept for Techfest IIT Bombay.

The project reimagines the Techfest landing experience through a cinematic 2D signal-transmission aesthetic built around radar visuals, technical grids, frequency waves, editorial typography, and responsive motion.

## Concept

Signal / 30 presents Techfest as a high-energy transmission for curious minds.

The visual language combines:

- Radar-inspired interfaces
- Technical grid systems
- Frequency and signal graphics
- Editorial typography
- Scan and glow effects
- CSS-led motion and interaction

The entire experience is built without 3D assets.

## Features

- Pointer-reactive lighting on fine-pointer devices
- Animated radar and signal visuals
- Frequency-wave motion
- Scroll progress indicator
- Responsive navigation
- Mobile navigation menu
- Smooth anchor navigation
- Interactive programme cards
- Purposeful hover effects
- Keyboard-accessible navigation
- `prefers-reduced-motion` support
- Responsive layouts from mobile to wide desktop
